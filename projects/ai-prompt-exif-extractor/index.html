AI Prompt EXIF Extractor Pro

Standalone desktop utility to inspect PNG, JPG, and WebP files generated by AI models and extract hidden prompt parameters, seeds, and ComfyUI workflow JSON graphs.

Prompt Forensics Active · v1.0.0 Platform: Windows x64 License: MIT
Download PromptExtractor.exe GitHub Repository Raw Markdown (LLM) ↗

Overview

Generative image tools embed vital metadata (prompts, negative prompts, seeds, sampler names, CFG scales, and workflow graphs) across divergent chunk formats—PNG tEXt/iTXt chunks, EXIF UserComment blocks, or raw JSON trees. AI Prompt EXIF Extractor scans asset directories in bulk and compiles all generation parameters into structured text files.

Bulk Scanning Across Multiple Formats

Supports PNG, JPG, JPEG, and WebP images. Scans entire nested directories in a single operation.

Stable Diffusion / Automatic1111 Parsing

Extracts positive prompts, negative prompts, seed numbers, sampler settings, and model hashes.

ComfyUI Workflow Recovery

Unpacks embedded ComfyUI node graphs, exposing complete workflow pipeline settings.

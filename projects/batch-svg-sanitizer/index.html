Batch SVG Sanitizer Pro

High-performance standalone Windows utility that recursively cleans and optimizes SVG files for web deployment and digital stock marketplaces by stripping proprietary editor namespaces and XML metadata bloat.

Vector Sanitizer Active · v1.0.0 Platform: Windows x64 License: MIT

Overview

Vector files exported from graphics editors (Adobe Illustrator, Inkscape, CorelDRAW, Figma) contain megabytes of redundant XML overhead: proprietary namespaces, editor history tags, invisible helper layers, and bloated coordinate strings. Stock marketplaces (Freepik, Adobe Stock, Shutterstock) strictly penalize or reject files with XML bloat. Batch SVG Sanitizer cleans, minifies, and validates SVG files at high speeds while preserving 100% visual fidelity.

Proprietary Editor Namespace Stripping

Purges Illustrator i:pgf binary data, Inkscape sodipodi namespaces, and Sketch metadata.

Coordinate Precision Minification

Rounds floating-point coordinate decimals cleanly, reducing file size by 30% to 60% with zero observable visual degradation.

Recursive Nested Folder Processing

Batch processes hundreds of nested folders and thousands of vector assets with live progress and byte savings analytics.

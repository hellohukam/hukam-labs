Hukam Flow

Modern Chrome Manifest V3 batch automation tool and queue runner for Google Flow (flow.google.com). Engineered with dedicated dockable Side Panel, MAIN-world Angular event synthesis, and internal network payload interception.

Overview

Hukam Flow was engineered to solve the operational friction of running large, multi-prompt creative generation workflows on Google Flow (flow.google.com). Standard browser automation extensions break because Google Flow is an enterprise Angular single-page application that strictly verifies input event provenance and cancels synthetic dispatch events.

The Bottleneck

Users running hundreds of prompts must manually enter text, wait for render completion, and click download. Standard DOM recorders fail because Angular forms ignore simulated DOM keystrokes, and network timeouts frequently cause silent failures.

The Architecture

Hukam Flow executes through an isolated Chrome Side Panel, injects trusted event synthesis hooks directly into the page's MAIN execution world, listens to internal batchexecute network signals, and manages automated jitter-paced retries with prompt-indexed file naming.

Under the Hood: Technical Architecture

The extension is structured according to strict Manifest V3 separation of concerns without relying on bulky external frameworks:

// 1. Page Hook (MAIN world execution context)
function dispatchAngularEvent(target, value) {
  target.focus();
  target.value = value;
  target.dispatchEvent(new InputEvent('input', { bubbles: true, composed: true }));
  target.dispatchEvent(new Event('change', { bubbles: true }));
}

// 2. Service Worker Network Interception
chrome.webRequest.onCompleted.addListener((details) => {
  if (details.url.includes('batchexecute')) {
    chrome.tabs.sendMessage(details.tabId, { type: 'FLOW_BATCH_COMPLETED' });
  }
}, { urls: ['*://flow.google.com/*'] });

Key Capabilities & Features

Dedicated Chrome Side Panel UI

Dockable side panel opened via Alt + Shift + F. Keeps the primary Google Flow interface completely interactive and unobstructed.

MAIN-World Page Injection Hook

Bypasses Chrome extension content-script execution world boundaries to synthesize native trusted events that Angular form bindings register correctly.

Smart Auto Mode with Auto-Download

Sequential batch runner that submits prompts, monitors internal response signals, saves generated assets with prompt-indexed filenames, and progresses automatically.

Anti-Bot Jitter Pacing & Multi-Tab Isolation

Randomizes delays between generation requests (2.5s to 5.5s) to avoid server throttling. State is strictly tab-scoped so multiple tabs run concurrent batches safely.

100% Private & Local Execution

Zero telemetry, analytics, or remote API pings. Prompts and downloaded files remain entirely on the local client machine.

Installation & Setup

Hukam Flow is distributed directly as an open-source extension directory:

  1. Clone the repository: git clone https://github.com/hellohukam/hukam-flow.git
  2. Open Google Chrome or any Chromium browser and visit chrome://extensions/
  3. Enable Developer mode in the top right corner.
  4. Click Load unpacked and select the cloned directory.
  5. Navigate to flow.google.com and press Alt + Shift + F to launch the Side Panel.

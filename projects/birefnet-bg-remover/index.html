Overview

BiRefNet Pro AI is an offline Windows desktop application engineered for high-precision background removal. It leverages the state-of-the-art BiRefNet (Bilateral Reference Network) deep learning architecture, running via ONNX Runtime with native DirectML GPU acceleration. It excels at fine-detail matting—intricate hair strands, animal fur, transparent glassware, and complex silhouettes—surpassing standard salient object detectors.

Sub-Pixel Edge Precision

Deep bilateral reference network capturing fine hair strands, fur, and glass transparency without jagged halo artifacts.

DirectML GPU Acceleration

Native Windows DirectX 12 DirectML provider supporting NVIDIA RTX, AMD Radeon, and Intel Arc/Iris graphics cards with CPU fallback.

Multi-Worker Batch Queuing

Configurable concurrent processing workers for maximum hardware saturation across CPU and GPU.

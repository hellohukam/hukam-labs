Vector Craft Studio

Advanced full-stack raster-to-vector SVG studio with multi-layer color quantization and pure TypeScript Potrace Bézier curve tracing.

Overview

Vector Craft Studio is an open-source web application engineered for transforming bitmap illustrations, icons, and logos into clean, production-ready multi-layer SVG vector graphics. Instead of outputting single flat silhouette paths, it segments the source bitmap into discrete color levels (from 2 up to 32 layers) and traces each layer using a pure TypeScript implementation of the Potrace Bézier algorithm.

Multi-Layer Vector Tracing

Maintains illustration depth by generating ordered SVG path stacks that accurately reproduce color hierarchies.

Pure TypeScript Potrace Engine

Contour detection and curve smoothing execute completely in memory without requiring native C/C++ node-gyp bindings.

Interactive Color Palette Inspector

Live swatch inspector displaying extracted hex values, pixel counts, and layer coverage percentages.

Split-Screen Zoom & Pan Comparison

Compare the original raster graphic with the generated vector graphics side-by-side with synchronized zoom and pan controls.

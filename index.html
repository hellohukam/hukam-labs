Hukam Flow

Production-ready Chrome Manifest V3 workflow automation tool for Google Flow (flow.google.com). Features a dedicated dockable Side Panel, MAIN-world page hooks for Angular trusted events, real-time API response interception, and prompt-indexed auto-downloading.

The Real Problem Solved

Automating prompt batches on Google Flow fails because Angular cancels synthetic DOM events, network timeouts break long runs, and manual downloads lose prompt associations.

  • Dedicated Chrome Side Panel UI (Alt + Shift + F)
  • MAIN-world Angular event synthesis hook bypassing form validation barriers
  • Real-time interception of internal Google Flow batchexecute network APIs
  • Smart Auto Mode: Auto-run, wait, auto-download, with prompt-indexed file naming

Standalone Executable Active · v1.0.0 Vulkan NCNN

Hukam AI Upscaler Pro

Hardware-accelerated Vulkan Real-ESRGAN super-resolution desktop app for Windows x64. Bundles pre-converted weights into an ultra-portable 55MB single-file executable with resume logging and tile-based memory safety.

The Real Problem Solved

Super-resolution deep learning tools usually require 4GB+ of PyTorch/CUDA libraries (locking out AMD/Intel users) or expensive cloud subscriptions that leak sensitive creative artwork.

  • Hardware-accelerated Vulkan Real-ESRGAN running across NVIDIA, AMD, and Intel GPUs
  • Standalone 55MB executable with pre-bundled neural weights
  • Crash-resilient resume log surviving power cuts and batch pauses
  • Low-VRAM tile splitting preventing Out-Of-Memory crashes on laptop GPUs

Binary Forensics Active · v1.1.0 Lossless Reconstruction

AI Image Forensic Repair

Lossless pixel buffer reconstruction utility solving the infamous Adobe Illustrator "File format cannot be placed" error on AI images (Midjourney, ComfyUI, DALL-E) by rebuilding corrupt container headers.

The Real Problem Solved

Generative AI engines frequently generate non-standard PNGs with truncated chunks or unsynchronized markers that cause professional Adobe vector software to fail to import.

  • Synthesizes valid ISO standard PNG signatures and mandatory IHDR chunks
  • 100% lossless: preserves original RGB/RGBA raster buffer without recompression
  • Batch directory processing with automatic unplaced file recovery

Inside the Lab

Independent Software Craft

Hukam Labs is an independent technology workshop where Waleed Ahmad ("Hukam") experiments with local AI inference, desktop toolchains, and browser automation to build practical tools that solve real bottlenecks.

Rather than building speculative commercial SaaS applications with forced subscriptions, the lab focuses on standalone, executable software that creators and engineers can run locally on their own machines without external surveillance or cloud friction.

Origin in Daily Bottlenecks

Every utility here was born out of an actual production frustration: removing backgrounds from hundreds of graphics without recurring API fees, running super-resolution without NVIDIA CUDA driver conflicts, or repairing malformed image files for Adobe Illustrator.

When a tool proves effective in production, it is cleaned, documented, licensed under MIT or GPL, and published openly for the developer and creator community.

Built to Be Used

Core Engineering Principles

Useful software should be accessible. We believe practical engineering speaks through executable code, transparent repositories, and measurable workflow speedups.

01 // LOCAL FIRST

Tools execute directly on your CPU, GPU, or browser runtime. Prompts and media never touch remote servers.

02 // ACCESSIBLE

No subscription paywalls, artificial compute tokens, credit expiration, or registration gates.

03 // TRANSPARENT

Code is published under permissive MIT or GPL licenses. Anyone can inspect, audit, or fork freely.

04 // INDEPENDENT

Maintained independently without venture capital pressures or artificial marketing hype distorting UX.

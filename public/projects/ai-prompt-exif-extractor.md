## Overview

AI Prompt EXIF Extractor Pro is a Windows desktop application that inspects AI-generated image files (from Midjourney, Stable Diffusion, ComfyUI, NovelAI, and DALL-E) and extracts embedded generation parameters, seeds, model names, and workflow node graphs into clean, structured text catalogs.

## Key Features

- **Bulk Directory Scanning**: Process directories containing hundreds of AI images in a single scan.
- **Stable Diffusion Parameters**: Extracts embedded A1111/NovelAI generation parameters, CFG scales, sampler names, and negative prompts.
- **ComfyUI Workflow Recovery**: Unpacks embedded ComfyUI JSON node graphs, identifying input prompts and model checkpoints.
- **EXIF UserComment Parsing**: Reads proprietary EXIF UserComment metadata chunks written by Midjourney and DALL-E.
- **Structured Text Export**: Automatically outputs compiled catalogs into `AI_Prompts_Extracted.txt`.
- **Thread-Safe Dark UI**: Responsive desktop GUI with live progress reporting and instant cancel capability.

## Technical Specifications

- **Engine**: Python, Pillow, custom binary chunk reader
- **Platform**: Windows 10 / Windows 11 (64-bit)
- **Packaging**: Portable PyInstaller executable (PromptExtractor.exe)
- **Supported Formats**: `.png`, `.jpg`, `.jpeg`, `.webp`
